# Vietnamese Finance Glossary

| English | Vietnamese | Usage |
| --- | --- | --- |
| Account | Tài khoản | Bank or budget account |
| Available | Khả dụng / Còn lại | Funds available; use “Còn lại” for category balances |
| Budget | Ngân sách | Budgeted amounts are “đã phân bổ” |
| Category | Danh mục | Budget category |
| Cleared / uncleared | Đã xác nhận / Chưa xác nhận | Transaction status |
| Overspent | Chi vượt ngân sách | Category spending above its budget |
| Payee | Người nhận | Person or business paid |
| Reconcile | Đối chiếu | Match account totals against bank records |
| Scheduled transaction | Giao dịch định kỳ | A transaction created from a schedule |
| Tracking budget | Ngân sách theo dõi | Budgeting by targets rather than envelopes |
| Transfer | Chuyển khoản | Account transfer; category movement uses “chuyển sang danh mục” |

Vietnamese plural variants use the same wording; keep each source key, placeholder, and tag intact.
