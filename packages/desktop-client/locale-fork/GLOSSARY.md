# Vietnamese Finance Glossary

| English | Vietnamese | Usage |
| --- | --- | --- |
| Account | Tài khoản | Bank, cash, credit, or budget account |
| Account balance | Số dư tài khoản | Current account total |
| Available | Còn lại | Funds available in a category |
| Budget | Ngân sách | The budget as a whole |
| Budgeted | Đã phân bổ | Amount assigned to a category |
| Category | Danh mục | Budget spending category |
| Category group | Nhóm danh mục | Group of budget categories |
| Cleared | Đã xác nhận | Transaction confirmed by the bank |
| Uncleared | Chưa xác nhận | Transaction not yet confirmed by the bank |
| Expense | Chi tiêu | Money leaving the budget |
| Income | Thu nhập | Money entering the budget |
| Inflow | Tiền vào | Positive transaction amount |
| Outflow | Tiền ra | Negative transaction amount |
| Overspent | Chi vượt ngân sách | Spending above available funds |
| Payee | Người nhận | Person or business paid |
| Reconcile | Đối chiếu | Match an account with bank records |
| Reconciled | Đã đối chiếu | Transaction included in reconciliation |
| Report | Báo cáo | Financial summary or analysis |
| Scheduled transaction | Giao dịch định kỳ | Transaction created from a schedule |
| Split transaction | Giao dịch tách | Transaction divided across categories |
| Starting balance | Số dư đầu kỳ | Initial balance for an account |
| Tracking account | Tài khoản theo dõi | Account outside the budget |
| Tracking budget | Ngân sách theo dõi | Budget based on targets rather than envelopes |
| Transaction | Giao dịch | Recorded movement of money |
| Transfer | Chuyển khoản | Movement between accounts |
| Transfer category | Chuyển sang danh mục | Movement between budget categories |
| Rule | Quy tắc | Automatic transaction action |
| Rollover | Chuyển số dư sang kỳ sau | Carry a category balance forward |
| Goal | Mục tiêu | Target for a category |
| Net worth | Giá trị ròng | Assets minus liabilities |

## Monte Carlo

`Monte Carlo` stays untranslated as a name. Author names (Guyton-Klinger, Kitces, Bengen) stay untranslated. Prefer `quỹ đầu tư` in headings and help text; `Quỹ N` is fine in tight table cells.

| English | Vietnamese | Usage |
| --- | --- | --- |
| Pot / Investment pots | Quỹ / Các quỹ đầu tư | Holding of money in the simulation |
| Scenario | Kịch bản | One simulated outcome |
| Run | Lượt chạy | One simulation pass |
| Percentile (50th) | Phân vị (phân vị thứ 50) | Ranked scenario outcome |
| Median | Trung vị | Middle outcome |
| Quartile | Tứ phân vị | Top and bottom quarter of outcomes |
| Success rate | Tỷ lệ thành công | Share of runs where money lasts |
| Survived | Còn đủ tiền | Run where money lasted |
| Ran out at age N | Hết tiền ở tuổi N | Run where money ran out |
| Withdrawal rule | Quy tắc rút tiền | How yearly withdrawals are set |
| Withdrawn | Đã rút | Amount taken out |
| Drain pots in order | Rút cạn các quỹ theo thứ tự | Withdrawal order option |
| Guardrails (Guyton-Klinger) | Ngưỡng bảo vệ (Guyton-Klinger) | Withdrawal rule |
| Ratcheting (Kitces) | Tăng theo bậc (Kitces) | Withdrawal rule |
| Floor & ceiling (Bengen) | Sàn & trần (Bengen) | Withdrawal rule |
| Boundaries | Ranh giới | Withdrawal rule with upper and lower rate limits |
| Prosperity rule | Quy tắc thịnh vượng | Raise withdrawals when the plan is doing well |
| Capital preservation rule | Quy tắc bảo toàn vốn | Cut withdrawals when the plan is under strain |
| Inflation | Lạm phát | Yearly price growth |
| Volatility (std dev) | Biến động (độ lệch chuẩn) | Spread of yearly returns |
| Return (%) | Lợi suất (%) | Yearly investment return |
| Tax bands (progressive) | Bậc thuế (lũy tiến) | Tax model |
| Before tax | Trước thuế | Amount before tax is taken |
| Taxable | Chịu thuế | Subject to tax |
| Stocks / Bonds / Cash | Cổ phiếu / Trái phiếu / Tiền mặt | Portfolio allocation |
| Contribution | Khoản đóng góp | Money added to a pot |
| Income streams | Nguồn thu nhập | Income during the plan |
| Spending phases | Giai đoạn chi tiêu | Spending plan by age range |
| Historical returns, shuffled | Lợi suất lịch sử, xáo trộn thứ tự | Return model |

Plural variants use the same wording. Preserve every source key, placeholder, tag, and plural suffix in `vi.json`.
