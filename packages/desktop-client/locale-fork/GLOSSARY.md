# Vietnamese Finance Glossary

| English               | Vietnamese               | Usage                                         |
| --------------------- | ------------------------ | --------------------------------------------- |
| Account               | Tài khoản                | Bank, cash, credit, or budget account         |
| Account balance       | Số dư tài khoản          | Current account total                         |
| Available             | Còn lại                  | Funds available in a category                 |
| Budget                | Ngân sách                | The budget as a whole                         |
| Budgeted              | Đã phân bổ               | Amount assigned to a category                 |
| Category              | Danh mục                 | Budget spending category                      |
| Category group        | Nhóm danh mục            | Group of budget categories                    |
| Cleared               | Đã xác nhận              | Transaction confirmed by the bank             |
| Uncleared             | Chưa xác nhận            | Transaction not yet confirmed by the bank     |
| Expense               | Chi tiêu                 | Money leaving the budget                      |
| Income                | Thu nhập                 | Money entering the budget                     |
| Inflow                | Tiền vào                 | Positive transaction amount                   |
| Outflow               | Tiền ra                  | Negative transaction amount                   |
| Overspent             | Chi vượt ngân sách       | Spending above available funds                |
| Payee                 | Người nhận               | Person or business paid                       |
| Reconcile             | Đối chiếu                | Match an account with bank records            |
| Reconciled            | Đã đối chiếu             | Transaction included in reconciliation        |
| Report                | Báo cáo                  | Financial summary or analysis                 |
| Scheduled transaction | Giao dịch định kỳ        | Transaction created from a schedule           |
| Split transaction     | Giao dịch tách           | Transaction divided across categories         |
| Starting balance      | Số dư đầu kỳ             | Initial balance for an account                |
| Tracking account      | Tài khoản theo dõi       | Account outside the budget                    |
| Tracking budget       | Ngân sách theo dõi       | Budget based on targets rather than envelopes |
| Transaction           | Giao dịch                | Recorded movement of money                    |
| Transfer              | Chuyển khoản             | Movement between accounts                     |
| Transfer category     | Chuyển sang danh mục     | Movement between budget categories            |
| Rule                  | Quy tắc                  | Automatic transaction action                  |
| Rollover              | Chuyển số dư sang kỳ sau | Carry a category balance forward              |
| Goal                  | Mục tiêu                 | Target for a category                         |
| Net worth             | Giá trị ròng             | Assets minus liabilities                      |

Plural variants use the same wording. Preserve every source key, placeholder, tag, and plural suffix in `vi.json`.
